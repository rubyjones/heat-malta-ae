# heat-malta-ae
This repository contains the R code and R Shiny forecasting application supporting MSc dissertation on the impact of heat on A&E attendances in Malta.

## Files
- `heatwaves_v1.R`: Complete analytical code for all results reported in paper.
- `app.R`: Interactive R Shiny decision-support application.

## Data Availability
The dataset (`heatwave_data_combined.xlsx`) contains the A&E attendance and meteorological data and is omitted due to data confidentiality restrictions.
